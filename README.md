# Hi, I'm Bishwas

I build software that solves everyday problems, and I build it end to end: the idea, the front end, the back end, the deployment, and the upkeep.

By day I am a senior software engineer working on real-time fraud detection, the kind of system that has to decide in milliseconds whether something looks legitimate. Off hours I build my own products the same way: small, useful tools that run in real life. One of them, Walking Counter, is a published iOS app for tracking walks with GPS routes, streaks, and achievements.

What you will find here:

- **Pasture Protocol** - a private, local-first AI assistant that runs on your own machine and talks to you over WhatsApp and Telegram
- **signup-fraud-signals** - a service that scores new account signups and flags the fraudulent ones
- **3d-flight-simulater** - a browser flight simulator flying over an endless generated coastline
- **pi-jarvis** - a voice assistant that runs on a Raspberry Pi in my house
- **pasture-reputation-scale** - an experiment in giving AI agents a reputation that is hard to fake
- **house-cost** - a calculator that shows what a house really costs, month to month

I mostly work in TypeScript and Next.js for products, Python for hardware and voice, and Flutter when something needs to be a phone app.
